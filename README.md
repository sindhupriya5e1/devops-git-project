# DevOps Git Project

## 📌 Project Overview

This project demonstrates a complete Git and GitHub workflow used in a DevOps environment. The project covers repository creation, branch management, feature development, pull requests, merge conflicts, conflict resolution, and maintaining a clean Git history.

The main purpose of this project is to understand how developers work with multiple branches and collaborate safely using Git and GitHub.

---

## 🎯 Objectives

- Create and manage a GitHub repository.
- Work with multiple Git branches.
- Develop features independently.
- Merge changes between branches.
- Create and review Pull Requests.
- Understand and resolve merge conflicts.
- Maintain a clean and meaningful Git history.
- Follow a practical DevOps Git workflow.

---

## 🛠️ Tools and Technologies Used

- Git
- GitHub
- GitHub Pull Requests
- Git Branches
- Git Merge
- Git Conflict Resolution
- Markdown
- Git Bash / Command Line

---

## 📂 Project Files

The repository contains different files created during the Git workflow:

- `feature.txt` – Feature branch changes
- `new-change.txt` – New changes added to the project
- `new-change-2.txt` – Additional changes
- `pr-change.txt` – Pull Request related changes
- `conflict.txt` – File used to demonstrate a merge conflict
- `git-workflow.md` – Git workflow documentation
- `README.md` – Project documentation

Screenshots are also included to document the complete workflow.
