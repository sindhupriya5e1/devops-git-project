\# Git Workflow Documentation



\## 1. Repository Initialization

\- Initialized the project using Git.

\- Created the main branch.

\- Added project files to Git.

\- Created the initial commit.



\## 2. Branching Strategy

The project uses the following branches:

\- `main` - Stable and final code.

\- `dev` - Development work.

\- `feature` - Feature development.



\## 3. Feature Development

\- Created a feature branch from the development workflow.

\- Added changes in the feature branch.

\- Committed the changes with meaningful commit messages.



\## 4. Pull Request

\- Created a Pull Request from the feature branch to the main branch.

\- Reviewed the changes.

\- Merged the Pull Request into the main branch.



\## 5. Git Tag

Created a version tag for the project:



`v1.0` - Version 1.0



\## 6. .gitignore

The `.gitignore` file is used to prevent unnecessary or sensitive files from being tracked by Git.
